# Домашнее задание по объектно-ориентированному программированию

## Описание
Реализованы базовые классы для моделирования товаров и категорий интернет-магазина.

## Требования
- Python 3.14+
- Poetry (менеджер зависимостей)

## Зависимости
+ ### Основные
  * **Python** 3.14+
  
+ ### Инструменты разработки
  * **flake8** >=7.4.1 (Проверка кода на соответствие стилю написания, который использует PEP 8 в качестве руководства.)
  * **black** >=26.10.1 (Автоматическое форматирование кода.)
  * **isort** >=9.0.2 (Сортировка импортов в коде.)
  * **pytest** >=9.1.1 (Фреймворк для написания и запуска тестов.)
  * **pytest-cov** >=7.1.0 (Плагин для проверки покрытия кода тестами.)

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/olgach-cmd/DZ_OOP.git
cd DZ_OOP
```
2. Установите зависимости:
```
poetry install
```

## Тестирование:

**Запуск всех тестов:**
```
poetry run pytest
```
**Запуск тестов с выводом процента покрытия кода в терминал:**
```
poetry run pytest --cov=src
```
**Генерация подробного HTML-отчета о покрытии:**
```
poetry run pytest --cov=src --cov-report=html
```
После выполнения этой команды в корне проекта обновится папка *htmlcov*. 
Чтобы просмотреть детальный отчет о том, какие строки кода покрыты тестами (подсвечены зеленым), 
а какие нет (подсвечены красным), откройте файл *htmlcov/index.html* в любом браузере.

## Функциональность
- **Класс `Product`**: описывает отдельный товар с атрибутами: название, описание, цена и количество на складе, цена хранится в приватном атрибуте `__price`.
  * геттер `price` возвращает значение приветного атрибута `__price`
  * сеттер `price` изменяет цену продукта, если она больше 0, противном случае выводится сообщение в консоль "*Цена не должна быть нулевая или отрицательная*" без изменения цены 
  * метод `new_product` принимает на вход параметры товара в словаре и возвращать созданный объект.
- **Класс `Category`**: объединяет товары в категорию, хранит название и описание категории, товары храняться в приватном атрибуте `__products`:
  * сеттер `products` выводит список товаров в виде строк в формате "*Название продукта, 80 руб. Остаток: 15 шт.*"
  * метод `add_product` принимает на вход объект класса `Product` и записывает в приватный атрибут списка товаров.
  * глобальные счетчики на уровне класса:
    - `category_count`: общее количество созданных категорий.
    - `product_count`: общее количество товаров во всех категориях.
- **Покрытие тестами**: написаны модульные тесты с использованием `pytest` и фикстур для проверки корректной инициализации объектов и методов.
